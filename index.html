Features

Everything you need to stay on top of money.

A complete personal finance toolkit in one quiet, focused app — built for the Philippine wallet first, then the world.

🫧

Glassmorphism, done tastefully

Every card is a frosted pane: translucent fill, hairline edge, soft top sheen — real depth from aurora orbs behind it. Dark mode included, cross-fading live.

👛

22 official bank tiles

GCash, Maya, Coins.ph, GrabPay, ShopeePay, BPI, BDO, Metrobank and 15 more. Logo, name and color fill in automatically — just type the balance.

🔔

Purchase detection

Paste any e-wallet or bank SMS and Aiserie reads the amount and direction on-device, then pre-fills a transaction. No message access, no monitoring.

🧾

Receipt scanning

On-device OCR (Google ML Kit) reads the total from a photo of a receipt and defaults to the Groceries category. Nothing is uploaded.

🧠

Finance advisor

Safe-to-spend per day, month-end projections, savings rate, category concentration warnings, momentum and recurring-bill reminders.

✅

Things-to-do

Money chores with springy check-offs, star pinning and a progress ring so the small admin never piles up.

🐷

Savings goals

Piggy banks with progress, contributions and withdrawals — watch the trip, the gadget, the emergency fund fill up.

📊

Visual reports

Category donut chart, 6-month income/expense bars, month-by-month navigation. Export to CSV and PDF for any period.

🔁

Recurring & budgets

Daily/weekly/monthly/yearly schedules with deterministic ids so re-runs never duplicate money. Budget envelopes nudge you at 50/75/90/100%.

FAQ

Questions, answered.

Is Aiserie Tracks really free?

Yes. Android is a signed APK from GitHub Releases. iPhone is an installable PWA. No ads, no account, no in-app purchases. The source is MIT licensed.

Where is my data stored?

Entirely on your device — AsyncStorage on native, localStorage on web. The only network call is a public GitHub release check for update nudges. Backup files are written locally or shared via the system share sheet; nothing is uploaded.

Does receipt scanning send photos anywhere?

No. OCR uses Google ML Kit, fully on-device. The module is loaded lazily and never bundled into the web build. On web and in Expo Go, the app falls back to manual entry instead of crashing.

Can I switch currencies?

The default is PHP, but you can switch to USD, EUR, GBP, JPY, SGD and more in Settings. Reports and exports reflect your choice.

What happens if I update the app?

Updating keeps every record. On boot the app checks GitHub Releases; if a newer version exists, a glass "Update available" card appears with a deep link to the latest release. There's a 3-day snooze and a manual check in Settings.

How do backups work?

One JSON file with everything. Import validates structure and sanitizes every entry (drops corrupt rows, dedupes ids, clamps values) before writing — then merges without duplicating, or replaces everything after a double confirmation.

Is the app crash-proof?

Malformed records are repaired at load or paused, never fatal. A root error boundary swaps any render bug for a branded recovery screen. Every money counter runs on disjoint animation-driver graphs.
